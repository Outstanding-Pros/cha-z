차량 화면의 QR을 찍어 연결하세요

정차 중에 차~즈 → 결과 화면의 ‘폰으로 보내기’ 또는 설정 → ‘폰 연결’에서 QR이 나와요.

말로 조작하기

버튼을 누르고 “찍어줘”, “폰으로 보내줘”처럼 말해 보세요.

실내 → 전방 → 후방 3장을 찍어 한 번에 차로 보내요. 차 화면 갤러리에 한 묶음으로 저장돼요.

받은 사진

아직 받은 사진이 없어요. 차에서 “차즈 폰으로 보내줘”라고 말해 보세요.

카메라 준비 중…

찍은 사진만 차로 보내요 (실시간 화면은 보내지 않아요).
