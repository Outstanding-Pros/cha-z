차량 화면의 QR을 찍어 연결하세요

정차 중에 차~즈 → 결과 화면의 ‘폰으로 보내기’ 또는 설정 → ‘폰 연결’에서 QR이 나와요.

말로 조작하기

버튼을 누르고 “찍어줘”, “폰으로 보내줘”처럼 말해 보세요.

대시보드에 폰을 세워 두면 차에서 “차즈”라고 할 때 이 폰이 실내 사진을 찍어요.
